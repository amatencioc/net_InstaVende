# UI MVC heredada (solo referencia)

Esta carpeta contiene la interfaz Razor/MVC original (controladores, vistas, ViewModels y estáticos).
**No se compila** y no forma parte de la aplicación: el panel se reimplementa como SPA en `frontend/`
consumiendo la API REST de `src/InstaVende.Web`.

Se conserva temporalmente como referencia funcional (campos, textos, reglas de negocio) mientras se
completa la paridad de cada módulo. Puede eliminarse cuando el SPA cubra todas las pantallas.
